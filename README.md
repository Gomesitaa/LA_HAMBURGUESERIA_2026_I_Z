# LA_HAMBURGUESERIA_2026_I_Z

## Descripción

**LA_HAMBURGUESERIA_2026_I_Z** es un videojuego web desarrollado con **HTML, CSS y JavaScript** cuyo objetivo es poner a prueba la rapidez, la memoria visual y la precisión del jugador.

El jugador controla a un chef que debe preparar hamburguesas siguiendo una **tarjeta ilustrada de receta**. Cada receta se genera de forma aleatoria y muestra el orden exacto en el que deben colocarse los ingredientes.

Durante la partida caerán ingredientes y objetos basura desde la parte superior de la pantalla. El jugador deberá atrapar únicamente el ingrediente correcto según el paso actual de la receta. Si recoge un ingrediente fuera del orden indicado o un objeto basura, perderá una vida.

Al completar correctamente una hamburguesa, el jugador obtiene puntos adicionales y avanza automáticamente al siguiente nivel con una nueva receta.

---

## Características principales

- Sistema de recetas ilustradas aleatorias.
- Más de 20 recetas diferentes.
- Validación del orden correcto de los ingredientes.
- Sistema de puntaje.
- Sistema de vidas.
- Niveles progresivos.
- Animación de "Pedido Completado".
- Pantalla de Game Over.
- Movimiento mediante teclado.
- Interfaz desarrollada con HTML y CSS.
- Lógica implementada con JavaScript.

## Mecánica del juego

1. Se genera una receta ilustrada aleatoria.
2. La receta aparece durante unos segundos en el centro de la pantalla.
3. Luego se mueve a la esquina superior derecha como referencia.
4. El jugador debe atrapar únicamente el ingrediente que corresponde al siguiente paso de la receta.
5. Si recoge un ingrediente incorrecto o basura, pierde una vida.
6. Al completar correctamente la hamburguesa obtiene un bono de puntos y comienza un nuevo nivel.

---

## Objetivo

Construir la mayor cantidad posible de hamburguesas siguiendo exactamente el orden indicado en cada receta para obtener el mayor puntaje.
